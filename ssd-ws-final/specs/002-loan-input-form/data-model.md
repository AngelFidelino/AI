# Data Model: Loan Input Form

**Feature**: 002-loan-input-form
**Date**: 2026-04-15

## Entities

### 1. LoanParams

**Description**: Represents the user-entered loan parameters from the form. Used as component state and transformed into an API request body.

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| `amount` | `string` | Controlled input; validated before submission | Loan principal amount in USD (string for input control) |
| `term` | `string` | Controlled input; validated before submission | Loan term in months (string for input control) |
| `rate` | `string` | Controlled input; validated before submission | Annual interest rate as percentage (string for input control) |

**Validation Rules** (FR-002 through FR-007):
- `amount`: Required, must be a valid positive number > 0, must not exceed 10,000,000
- `term`: Required, must be a valid positive integer >= 1, must not exceed 600, no decimals allowed
- `rate`: Required, must be a valid number >= 0 and <= 100, max 2 decimal places

**TypeScript Interface** (form state):
```typescript
interface LoanFormState {
  amount: string;
  term: string;
  rate: string;
}
```

**TypeScript Interface** (API request — after transformation):
```typescript
interface LoanCalculateRequest {
  amount: number;
  term_months: number;
  annual_rate: number;
}
```

**Field Mapping** (form → API):
| Form Field | API Field | Transformation |
|-----------|-----------|----------------|
| `amount` | `amount` | `Number(amount)` |
| `term` | `term_months` | `Number(term)` |
| `rate` | `annual_rate` | `Number(rate)` |

---

### 2. ValidationErrors

**Description**: Represents client-side validation errors. Maps field names to error messages for inline display.

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| (key) | `string` | One of: `amount`, `term`, `rate` | Field identifier |
| (value) | `string` | Non-empty when error present | Human-readable error message |

**TypeScript Interface**:
```typescript
type ValidationErrors = Record<string, string>;
```

**Error Message Catalogue** (from spec acceptance scenarios):

| Field | Condition | Error Message |
|-------|-----------|---------------|
| `amount` | Empty | "Please enter a loan amount" |
| `amount` | Non-numeric | "Please enter a valid number" |
| `amount` | <= 0 | "Loan amount must be greater than 0" |
| `amount` | > 10,000,000 | "Loan amount must not exceed 10,000,000" |
| `term` | Empty | "Please enter a loan term" |
| `term` | Non-numeric | "Please enter a valid number" |
| `term` | <= 0 | "Loan term must be at least 1 month" |
| `term` | Decimal (e.g., 12.5) | "Please enter a whole number for months" |
| `term` | > 600 | "Loan term must not exceed 600 months" |
| `rate` | Empty | "Please enter an interest rate" |
| `rate` | Non-numeric | "Please enter a valid number" |
| `rate` | < 0 or > 100 | "Interest rate must be between 0 and 100" |
| `rate` | > 2 decimal places | "Interest rate allows up to 2 decimal places" |

---

### 3. LoanResult

**Description**: Represents the successful calculation response from the backend API. Passed to parent component for display.

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| `monthly_payment` | `number` | > 0, 2 decimal places | Fixed monthly payment amount |
| `total_payment` | `number` | > 0, 2 decimal places | Total amount paid over loan term |
| `total_interest` | `number` | >= 0, 2 decimal places | Total interest paid over loan term |
| `schedule` | `Installment[]` | Length = term_months | Complete amortization schedule |

**TypeScript Interface**:
```typescript
interface LoanResult {
  monthly_payment: number;
  total_payment: number;
  total_interest: number;
  schedule: Installment[];
}
```

---

### 4. Installment

**Description**: A single row in the amortization schedule (consumed from backend, not generated by frontend).

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| `payment_number` | `number` | Sequential, 1 to N | Installment sequence number |
| `payment_amount` | `number` | > 0, 2 decimal places | Total payment for this month |
| `principal_portion` | `number` | >= 0, 2 decimal places | Amount applied to principal |
| `interest_portion` | `number` | >= 0, 2 decimal places | Amount applied to interest |
| `remaining_balance` | `number` | >= 0, 2 decimal places | Balance after this payment |

**TypeScript Interface**:
```typescript
interface Installment {
  payment_number: number;
  payment_amount: number;
  principal_portion: number;
  interest_portion: number;
  remaining_balance: number;
}
```

---

### 5. ApiError

**Description**: Represents an error response from the backend, including structured validation errors.

| Field | Type | Constraints | Description |
|-------|------|-------------|-------------|
| `error` | `string` | e.g., `"validation_error"` | Error category |
| `details` | `FieldError[]` | At least 1 entry (for validation errors) | Per-field error details |

### 5a. FieldError

| Field | Type | Description |
|-------|------|-------------|
| `field` | `string` | Name of the invalid field (backend field name) |
| `message` | `string` | Human-readable error description |

**TypeScript Interfaces**:
```typescript
interface ApiError {
  error: string;
  details: FieldError[];
}

interface FieldError {
  field: string;
  message: string;
}
```

**Backend-to-Frontend Field Name Mapping** (for displaying backend validation errors):
| Backend Field | Frontend Field |
|--------------|----------------|
| `amount` | `amount` |
| `term_months` | `term` |
| `annual_rate` | `rate` |

---

### 6. LoanFormProps

**Description**: Component props interface defining the contract between LoanForm and its parent.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `onCalculate` | `(result: LoanResult) => void` | Yes | Callback invoked with calculation results on success |

**TypeScript Interface**:
```typescript
interface LoanFormProps {
  onCalculate: (result: LoanResult) => void;
}
```

## Relationships

```
LoanFormProps.onCalculate
       │
       ▼
LoanForm (component)
  ├── state: LoanFormState {amount, term, rate}
  ├── state: ValidationErrors {field → message}
  ├── state: isLoading: boolean
  ├── state: apiError: string | null
  │
  ├──[validate]──→ ValidationErrors
  │                 ├── {} (empty = valid)
  │                 └── {field: "error message"}
  │
  ├──[submit (valid)]──→ loanApi.calculateLoan(params)
  │                       ├── 200 OK → LoanResult → onCalculate(result)
  │                       ├── 400 → ApiError → display backend errors
  │                       ├── 500 → apiError = "An error occurred..."
  │                       ├── Network → apiError = "Unable to connect..."
  │                       └── Timeout → apiError = "Request timed out..."
  │
  └──[submit (invalid)]──→ display ValidationErrors inline
```

## State Transitions

```
[Initial]
  │
  ├── User types in field → update LoanFormState
  │
  ├── Field loses focus (blur) → validate single field
  │   ├── Valid → clear error for field
  │   └── Invalid → set error for field
  │
  ├── User clicks Calculate
  │   ├── Validation fails → show all errors, stay in [Initial]
  │   └── Validation passes → transition to [Loading]
  │
  [Loading]
  │   ├── isLoading = true
  │   ├── Submit button disabled, shows "Calculating..."
  │   │
  │   ├── API returns 200 → [Success]
  │   │   └── call onCalculate(result), isLoading = false
  │   │
  │   ├── API returns 400 → [Backend Error]
  │   │   └── display field-specific errors, isLoading = false
  │   │
  │   ├── API returns 500 → [Error]
  │   │   └── apiError = "An error occurred...", isLoading = false
  │   │
  │   ├── Network failure → [Error]
  │   │   └── apiError = "Unable to connect...", isLoading = false
  │   │
  │   └── Timeout (10s) → [Error]
  │       └── apiError = "Request timed out...", isLoading = false
  │
  [Success] / [Error] / [Backend Error]
  │   └── Form remains editable → User can modify and resubmit
  │       └── On resubmit → clear previous errors → [Loading]
```
